📘 Hackathon Rule Book

Guidelines for fairness, transparency, and technical excellence.

01. AI Usage

Use of AI chatbots, AI code generators, or automation tools is strictly prohibited. Violators will be disqualified.

02. Hardware

Personal laptops, mobile phones, and external storage (USB) are not allowed. Use only lab systems.

03. System Allocation

Dedicated PC systems are provided to each team. Accessing unauthorized systems is not permitted.

04. Internet Access

Access will be limited and monitored. Only permitted resources related to the problem statement are allowed.

05. Team Conduct

Teams must work independently. Collaboration between different teams leads to immediate disqualification.

06. Submission

Projects must be submitted within the given timeframe. Late entries will not be accepted for evaluation.
